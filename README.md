# 🚀 Shubham Jadhav - Portfolio

A stunning, fully animated cyberpunk-themed portfolio website showcasing my skills and projects as a MERN Stack Developer.

## ✨ Features

- 🌃 **Cyberpunk Theme** - Neon blue/purple color scheme with glowing effects
- 💫 **Matrix Rain Background** - Animated falling code effect
- ⌨️ **Typing Animation** - Dynamic role display
- 🎨 **Smooth Animations** - Scroll-triggered animations throughout
- 📱 **Fully Responsive** - Works perfectly on all devices
- 🖱️ **Interactive Elements** - Hover effects, cursor trails, and more
- ⚡ **Fast & Lightweight** - Pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3 (with advanced animations)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts (Orbitron & Rajdhani)

## 🚀 Deployment

### Deploy to Netlify

1. **Via Netlify Drop:**
   - Go to [Netlify Drop](https://app.netlify.com/drop)
   - Drag and drop the entire folder
   - Your site will be live instantly!

2. **Via Netlify CLI:**
   ```bash
   npm install -g netlify-cli
   netlify deploy --prod
   ```

3. **Via GitHub (Continuous Deployment):**
   - Go to [Netlify](https://app.netlify.com)
   - Click "New site from Git"
   - Connect your GitHub repository
   - Deploy!

### Deploy to GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" section
3. Select "main" branch as source
4. Click "Save"
5. Your site will be live at: `https://shubhamjadhav0715.github.io/portfolio/`

### Deploy to Vercel

1. Install Vercel CLI:
   ```bash
   npm install -g vercel
   ```

2. Deploy:
   ```bash
   vercel --prod
   ```

Or simply:
- Go to [Vercel](https://vercel.com)
- Import your GitHub repository
- Deploy with one click!

## 🎨 Customization

### Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-color: #00f0ff;      /* Cyan */
    --secondary-color: #ff00ff;    /* Magenta */
    --accent-color: #00ff88;       /* Green */
}
```

### Content
- Update personal information in `index.html`
- Modify projects in the Projects section
- Change skills in the Skills section
- Update contact information
